# Plantaloon

**A free, private plant-care app for Android.** Keep track of your houseplants, get reminders to water, fertilize and repot, and keep a care journal. No account, no cloud, no ads, no tracking.

> Early development. Nothing to install yet.

## Development

Plantaloon is an [Expo](https://expo.dev) app (React Native, TypeScript, Expo Router).

```bash
npm install
npx expo start      # try it in Expo Go
npx tsc --noEmit    # typecheck
npx expo lint       # lint
```
